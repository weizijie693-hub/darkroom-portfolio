# 暗房工作室 · DARKROOM STUDIO

> 摄影作品集

## 页面结构

- **首页 Hero** — 全屏沉浸式入口，暗调背景 + 胶片颗粒质感
- **关于 About** — 摄影师简介，中英双语，实时统计
- **作品 Gallery** — 系列分组展示 + 分类筛选 + 排序切换 + 全屏灯箱浏览
- **3D 展厅** — 六边形 CSS 3D 画廊，6 面墙拖拽旋转，照片自动轮播，点击墙面放大
- **游戏 Game** — 内嵌「暗房潜影」像素小游戏（11 关）
- **联系 Contact** — 联系方式 & 社交链接

## 功能

- 画廊筛选 + 时间序/随机排序切换
- 全屏灯箱：← → 切换 / ESC 关闭 / 快门帘动画
- 3D 六边形展厅：拖拽旋转 / 照片自动轮播 / 点击墙面放大 / ESC 关闭
- 键盘导航：↑ ↓ 切换系列 / ← → 切换灯箱照片 / ESC 关闭
- 暗房美学：噪点 / 暗角 / 漏光 / 安全灯红晕 / 取景框光标 / 胶片计数器
- 页脚与关于页数据实时统计
- 回到顶部按钮

## 本地打开

直接双击 `index.html` 即可在浏览器中浏览。

## 技术栈

纯前端，零依赖：
- HTML5 + CSS3 (Flexbox, Grid, CSS Variables, Animations, 3D Transforms)
- Vanilla JavaScript (Intersection Observer, Lightbox, SVG)
- Google Fonts (Inter, Noto Serif SC, Playfair Display)
